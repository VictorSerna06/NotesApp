# 📝 NotesApp

Aplicación Android para **gestionar notas personales**.  
Permite agregar, editar, eliminar, marcar notas como completadas, **búsqueda en tiempo real**, así como una interfaz minimalista y moderna basada en **Material Design**.

---

## Características

- **SplashScreen** al iniciar la aplicación.
- Crear, editar y eliminar notas.
- **Búsqueda en tiempo real** desde la Toolbar.
- Estado de nota:
  - Completada (switch verde)
  - Pendiente (switch amarillo)
- **FloatingActionButton** para agregar notas.
- Formulario en **AlertDialog** con validación de campos.
- **Swipe a la derecha** para eliminar con:
  - **Snackbar con opción Deshacer**
- **Click prolongado** para editar notas.
- Soporte de tema claro y oscuro.

## Instalación

1. Clona el repositorio:

```bash
git clone https://github.com/VictorSerna06/NotesApp.git
```
2. Abre el proyecto en Android Studio.
3. Sincroniza Gradle y ejecuta en un emulador o dispositivo físico.
